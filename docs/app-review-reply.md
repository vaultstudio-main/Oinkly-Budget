# Reply to App Review (Guideline 2.1, Information Needed)

Apple is not rejecting the app. This is a request for information because the developer account is new. Reply in the Resolution Center with the text below, paste the same text into **App Review Information, Notes**, and attach the screen recording.

## Before you reply

1. **Screen recording on a physical Mac** running the latest macOS. Use Screenshot (Shift-Command-5), Record Entire Screen. Start with the app closed, then launch it from the Dock. Keep it to 3 to 5 minutes. See the shot list below.
2. **Sample file (optional but helpful).** The app starts empty. Save a `.pig` backup from a copy with sample data (Settings ▸ Data & Backup ▸ Manual Backup ▸ Save Backup…), and attach it in the Notes section if Apple lets you attach a file, or say it is available on request. The reviewer can use Settings ▸ Data & Backup ▸ Manual Backup ▸ Restore Backup… to load it.
3. **Upload the build from the same Mac you record on**, so what Apple sees matches the recording.

## Shot list for the recording

1. Quit the app, then launch it from the Dock. Show the startup screen and the main window.
2. Create an account (Accounts ▸ Add Account…): name, type, opening balance.
3. Add a transaction (File ▸ New Transaction): payee, amount, category.
4. Open the transaction's details (double-click), then close it.
5. Show a transfer between two accounts.
6. Add a bill and pay it (Bills, Pay a Bill).
7. Show the budget and a goal.
8. Show a report and the spending charts.
9. Open Settings: Reminders tab (custom reminder), Import & Export tab (export a backup, CSV import).
10. Show Help and About.
11. Show that nothing asks for a login, a bank connection or a purchase inside the app.

## Text to paste (reply and Notes field)

**1. Screen recording**
Attached. It was recorded on a physical Mac running the latest macOS. It starts with launching the app and shows the typical flow: creating an account, adding transactions, transfers, bills, budgets, goals, reports, reminders and backup. The app has no account registration, login or account deletion, no user-generated content shared with other people (so no reporting or blocking), and no in-app purchases or paid features inside the app.

**2. Purpose and audience**
Oinkly Budget is a personal finance app for Mac. It is for people who want to keep track of their own money by entering their own transactions, the way a paper check register or a desktop checkbook program works. It helps them keep a register for each account, track bills and due dates, set budgets and savings goals, and view reports. It deliberately does not link to bank accounts. People enter and check their own numbers, which keeps their data private. The app is a one-time purchase.

**3. Setup and access**
No sign-in, account or login is needed. On first launch the app is empty. To explore: add an account (Settings ▸ Accounts ▸ Add Account…, or the prompt on the main window), then add transactions with File ▸ New Transaction.  Help is available from the Help menu.

**4. External services**
None. The app does not use any servers, data providers, authentication services, payment processors, analytics, advertising or AI services. It makes no network requests. All data is stored on the user's Mac. Local notifications (bill and custom reminders) use Apple's UserNotifications framework on the device.

**5. Regional differences**
None. The app works the same in every region. Amounts use the user's Mac currency and date formatting settings.

**6. Regulated industry or protected material**
The app does not provide banking, payments, lending, investing or tax services and does not connect to financial institutions. It is a record-keeping tool for the user's own information. It includes no protected third-party material. The app icon, artwork and text are original to Donald Stibich.
