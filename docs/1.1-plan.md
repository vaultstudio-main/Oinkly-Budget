# Oinkly Budget 1.1: plan

Nothing here is started. Everything in 1.0 is finished first; new work waits for the release (see `1.0-release-plan-final.md`).

## 1. Automatic transfer between computers

Asked for by a tester: a folder in Documents that works like the shared folder, so her data follows her from one computer to the next without a manual backup and restore.

**What she wants:** pick a folder (for example in Documents or iCloud Drive). The app keeps the data there on its own, and the other Mac picks it up.

**What has to be decided first**
- **Live sharing or hand-over.** The shared folder has a lock, check-out and check-in because two people can use it at once. A folder that syncs through iCloud Drive or Dropbox cannot give the instant, single copy the lock relies on, so two Macs could both hold the lock and one save would overwrite the other. The safe design is a hand-over: one Mac at a time owns the data. Closing the app writes one packed file to the folder; opening it on the other Mac asks "Newer data found, use it?" and takes it. No live editing on two Macs at once.
- **Sandbox.** A folder the person picks needs the user-selected-folder permission and a saved bookmark, so the app can reopen it. The existing exception covers only `/Users/Shared/OinklyBudget`. The App Review notes need a line about it.
- **Conflicts.** If both Macs changed the data since the last hand-over, the app must say so and let the person choose which to keep, after making a safety copy of the other. It never merges silently.

**Reuse:** the packed file and safety copy from Back Up Data, the history and save log from shared data, `info.json` (revision, savedAt/By, fileID) to see which side is newer, and the closing countdown.

**Tests:** the hardening tests for the shared folder, extended with: sync service delivers a file late, a half-written file, both Macs changed, folder missing or unplugged, and the data from a newer app version.

**Done when:** two Macs hand data back and forth through a synced folder with no loss in any of those cases, and Help, the website and the release notes describe it.
