# Docs and Roadmap

Oinkly Budget is open source (GNU GPL v3, see [../LICENSE](../LICENSE)). This folder is where the project plans in the open.

Put here:

- the **roadmap**: what is planned for each coming release, and why
- **plans** for features, data safety, releases and anything else being designed before it is built
- other **notes** that help people understand where the project is going

Each document says which release it is for, so the roadmap can be read from the top.
